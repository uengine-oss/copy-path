Copy Path for Windows 11 - 1.0

설치
1. ZIP을 Windows PC에 다운로드하고 모든 파일을 압축 해제합니다.
2. Install.cmd를 더블클릭합니다. 관리자 권한은 필요하지 않습니다.
3. 탐색기에서 파일/폴더 우클릭 → 더 많은 옵션 표시를 선택합니다.
   Shift+F10으로도 기존 컨텍스트 메뉴를 열 수 있습니다.

메뉴
- Copy Path: 선택한 파일/폴더의 전체 경로를 따옴표 없이 복사합니다.
- Recent Paths: 최근 10개의 경로를 다시 복사합니다.
- Open Paths: 최근 파일은 기본 앱으로, 폴더는 탐색기로 엽니다.
- 폴더 빈 공간에서 Copy Path를 누르면 현재 폴더 경로를 복사합니다.
- 목록은 파일명과 경로 앞부분만 표시합니다. 실제 경로는 생략하지 않습니다.
- 중복 경로는 하나만 유지합니다. 재복사하면 목록의 맨 앞으로 이동합니다.
- 복사 성공 알림이나 소리는 없습니다. 목록은 이 앱으로 복사한 경로만 기록합니다.

제한 및 검증
- Windows 11의 첫 번째 간소화 메뉴가 아니라 '더 많은 옵션 표시'에 표시됩니다.
- 한 번에 한 항목을 대상으로 합니다.
- Windows PowerShell 실행 시 매우 짧게 창이 나타날 가능성은 있습니다.
- macOS에서 작성한 패키지입니다. 실제 Windows 실행 검증은 아직 하지 못했습니다.
- 조직 정책이 PowerShell 실행을 제한하는 PC에서는 설치/실행되지 않을 수 있습니다.
- 오류는 %LOCALAPPDATA%\CopyPath\last-error.txt에 기록됩니다.

설치 위치: %LOCALAPPDATA%\CopyPath
경로 기록: 위 폴더의 history.json (이 PC에만 저장)
변경 범위: 현재 사용자의 탐색기 메뉴 레지스트리 및 위 파일들
시스템 실행 정책은 바꾸지 않습니다. 실행 명령에만 ExecutionPolicy Bypass를 사용합니다.
상주 프로세스나 네트워크 통신은 없습니다.

삭제
압축을 푼 폴더의 Uninstall.cmd를 실행합니다.
이 앱의 메뉴와 설치 파일 및 경로 기록을 제거합니다.

확인할 항목
한글/공백/&가 있는 이름, 파일, 폴더, 드라이브 루트, 빈 공간 메뉴,
최근 경로 재복사, 기본 앱 열기, 탐색기 재시작 후 기록 유지, 삭제 후 메뉴 제거.
